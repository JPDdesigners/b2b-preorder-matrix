B2B Matrix

Εμφάνιση πίνακα προπαραγγελιών

Βασικό χρώμα

Χρώμα για αποθήκευση, επιλογές και εστίαση. Η επιτυχία παραμένει πράσινη και τα σφάλματα κόκκινα.

Γραμματοσειρά

Ενεργό από προεπιλογή. Αν το απενεργοποιήσετε, χρησιμοποιείται η ενσωματωμένη system sans-serif γραμματοσειρά του matrix (Segoe UI / system font), χωρίς λήψη εξωτερικών fonts.

Γωνίες

Οι ρυθμίσεις εφαρμόζονται σε όλους τους πίνακες του καταστήματος κατά την επόμενη φόρτωσή τους.
